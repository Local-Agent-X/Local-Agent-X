# Harness campaign workspace

The working area for the local-model harness campaign: the audit
(`AUDIT.md`), its per-area notes (`audit-notes/`), the two briefs, the running
ledger (`HARNESS_LOG.md`), and the evidence scripts and traces
(`phase0-evidence/`, `phase1-evidence/`).

The ledger and audit are dated records that are appended to, not rewritten:
a path or number in an older entry is as of that entry's date and may have
moved since. Evidence scripts are tied to the machine they ran on. Neither is
covered by the build's doc-path check. For the current design, start at
[ARCHITECTURE.md](../../ARCHITECTURE.md).
