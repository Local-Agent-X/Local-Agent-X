# History

Finished plans, campaign logs, and design records for work that has shipped.
They describe the code as it was when they were written. Paths and numbers in
them are not kept current and are not checked by the build.

For the current design, start at [ARCHITECTURE.md](../../ARCHITECTURE.md); for
the facts that drift (modules, importers, oversized files), the generated
[codebase map](../codebase-map.md).

Every file moved here carries a banner at the top naming its date and the
current owner of the code it describes.
